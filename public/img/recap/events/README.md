# Sankhya event photo library

Each scheduled event has a folder. The existing fashion photograph and its responsive copies are in re-vogue/. Keep originals alongside browser-sized WebP copies.

Register chosen photographs in recap.photos in src/data.js using eventId, src, srcset, width, height and alt. Event names, days, categories and descriptions come from recap.events; they appear below the film, never over the photos.

Only registered, real photographs appear. Empty event folders do not generate placeholders or duplicate frames.
